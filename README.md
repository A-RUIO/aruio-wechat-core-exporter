# ARUIO 公众号核心数据导出器

一个在本机浏览器运行的 Chrome 扩展，用于从你已登录的微信公众号后台导出本人文章的核心数据。它会读取“已通知内容”和“未开启通知内容”两个栏目，合并分页结果并下载 CSV。

不需要 AppID、AppSecret、付费会员或单独提交账号密码。

## 功能

- 遍历“已通知内容”和“未开启通知内容”的全部分页。
- 按公众号文章 ID 去重，并在 CSV 中标明文章栏目。
- 读取阅读人数、平均阅读时长、分享、新增关注、在看、点赞、留言和收藏等可用指标。
- 缺失数据留空；无法读取详情时保留列表数据并标记状态。
- 结束后尽量恢复原先的栏目和页码。

CSV 字段：平台、内容分组、平台作品 ID、标题、发布日期、采集时间、数据截止日期、发布后天数、阅读人数、平均阅读时长、分享人数、新增关注、在看、点赞、留言、收藏、采集状态、备注。

## 安装

1. 下载本项目，解压到本机。
2. 在 Chrome 打开 `chrome://extensions/`，启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向本项目文件夹。
4. 刷新已经打开的微信公众号后台页面。

本扩展目前以未打包的开发者扩展形式分发。代码更新后，在扩展管理页点“重新加载”，然后刷新公众号后台。

## 使用

1. 登录你自己的微信公众号后台。
2. 打开“数据分析 → 内容分析”，停留在两个栏目中的任意一个。
3. 点击页面右下角的“导出核心数据”，或从 Chrome 工具栏打开扩展并点击导出。
4. CSV 会下载到浏览器默认下载目录，文件名为 `ARUIO-公众号核心数据-YYYY-MM-DD.csv`。

导出范围由后台两个栏目当前选择的日期范围决定。补录更早的文章时，先在后台扩大日期范围。

## 隐私与权限

- 所有采集和 CSV 生成都在你的浏览器本机完成。
- 扩展只在 `mp.weixin.qq.com` 上运行，并使用当前已登录的后台会话读取本人可见的数据。
- 不向开发者或第三方服务器发送数据；不保存 Cookie、Token、AppSecret 或登录密码。
- 导出的 CSV 不含 Cookie、后台 Token 或详情页地址。
- 扩展不会发布内容、评论、修改账号设置或尝试绕过验证码。

建议只在你有权访问的公众号账号中使用。安装前可直接检查 `manifest.json`、`collector.js` 和 `lib/core.js`。

## 限制与排障

- 微信公众号单篇详情页目前只统计文章发表后 30 天内的数据；CSV 会保留平台返回的数据截止日和说明。
- 后台页面改版、登录失效、限流或详情接口不可用时，扩展会保留能读取到的列表数据并标记“部分成功”，不会用猜测值补齐。
- 如果栏目切换或翻页超时，刷新公众号后台后重试。
- 日期筛选和文章可见范围仍由公众号后台决定。

## 开发

要求 Node.js。安装后可运行：

```sh
npm test
```

项目使用 Chrome Manifest V3，不包含构建步骤或运行时第三方依赖。

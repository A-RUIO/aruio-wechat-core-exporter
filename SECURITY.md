# Security policy

## Reporting a vulnerability

Please do not publish account data, cookies, tokens, or a working exploit in a public issue. Contact the repository maintainer privately through the GitHub security advisory feature, if enabled, or ask the maintainer for a private reporting channel.

Include the affected version, the steps needed to reproduce the issue, and its impact. Remove real account identifiers and session values from all examples.

## Scope

The extension is intended to read data visible in the user's own logged-in WeChat Official Account backend. It must not transmit collected data or credentials to an external service.
